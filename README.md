# yatzee_game
“A digital implementation of the classic Yahtzee dice game with scoring and dice-roll mechanics.”
Yahtzee Game

This project is a digital implementation of the classic Yahtzee dice game. It allows players to roll dice, choose scoring combinations, and compete to achieve the highest score based on traditional Yahtzee rules.

🚀 Features
🎲 Roll five dice up to three times per turn
🔄 Option to hold and re-roll selected dice
🧮 Automatic score calculation for all categories
📊 Scorecard tracking (Upper & Lower sections)
🏆 Final score summary with winner determination
🕹️ Gameplay

Players take turns rolling five dice and aim to achieve specific combinations such as:

Three of a Kind
Four of a Kind
Full House
Small Straight
Large Straight
Yahtzee (five of a kind)

Each combination can be used only once, so strategic decision-making is key!
created by using C language.
